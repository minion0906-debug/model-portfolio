# Image Viewer Upgrade

Updated the admin gallery image detail view.

## Controls
- Click an image to open the popup editor.
- Left / Right arrow keys: previous / next image.
- Escape: close popup.
- `+` or `=`: zoom in.
- `-`: zoom out.
- `0`: reset zoom and position.
- Mouse wheel: zoom in/out.
- Double-click: toggle zoom.
- Drag/pan while zoomed.
- Previous / Next buttons remain available.
- Existing title/description edit form and save flow are preserved.
